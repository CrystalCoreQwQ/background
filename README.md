## 简介

### ✨ 主要特性
- **独立设置**：每个网站可单独配置背景
- **智能文字颜色**：根据背景自动选择黑白文字
- **极致透明**：让代码框等元素永久透明
- **滤镜调节**：亮度/模糊实时调节
- **环绕小球**：优雅的控制面板

## 快速开始

### 第一步：安装脚本
1. 确保已安装油猴插件（Tampermonkey）
2. [点击此处安装脚本](#)（链接待补充）

### 第二步：上传背景
1. 打开任意网站（如 bilibili.com）
2. 找到页面右上角的**蓝色小球**🎨
3. 双击小球展开环绕菜单
4. 点击 **📁** 按钮上传图片
5. 裁剪图片后确认

### 第三步：调整效果
- **亮度调节**：点击 ☀️+ / ☀️-
- **模糊调节**：点击 🌀+ / 🌀-
- **文字颜色**：点击 🎨 切换（自动/白/黑）

## 核心功能详解

### 1. 背景图片设置
**上传流程：**
1. 点击 📁 选择图片
2. 在裁剪框中**调整选区**（比例锁定为当前窗口）
3. 点击“确认裁剪”

**提示：**
- 图片会自动压缩至合适大小
- 建议使用宽高比接近显示器的图片

### 2. 文字颜色智能调节
**三种模式：**
- **自动**：分析背景亮度，暗色背景用白字，亮色背景用黑字
- **白色**：强制使用白色文字
- **黑色**：强制使用黑色文字

**切换方法**：点击环绕小球中的 🎨

### 3. 极致透明模式
**作用**：让代码框、卡片、容器等元素彻底透明

**开启方法**：
1. 确保背景已开启
2. 点击环绕小球中的 **🔮**

**效果**：被覆盖的背景会完全显示，适合追求纯净界面的用户

### 4. 滤镜调节
**亮度调节**：
- 范围：0% - 200%
- 默认：100%
- 低于30%可能看不清文字

**模糊调节**：
- 范围：0px - 20px
- 默认：0px
- 适当模糊可减少背景干扰

## 高级功能

### 独立网站配置
脚本会为**每个网站保存独立设置**：
- 在 A 网站设置的背景不会影响 B 网站
- 修改设置后自动保存

### 设为全局默认
1. 点击 ⚙️ 打开更多菜单
2. 选择“⭐ 设为全局默认”
3. 当前设置会复制到默认配置
4. 其他未设置独立背景的网站将使用此默认

### 应用到所有网站
1. 点击 ⚙️ 打开更多菜单
2. 选择“🌐 应用到所有”
3. 当前设置会覆盖所有网站的配置

### 手动透明强制
如果某些元素未被背景覆盖：
1. 点击 ⚙️ → “🧹 手动透明”
2. 脚本会强制清理代码框背景

### 调试模式
点击 ⚙️ → “🔍 调试遮罩”
- 背景层会显示半透明红色
- 用于检查覆盖范围
- 再次点击关闭

### 面板位置记忆
- 拖动中心球可改变位置
- 位置会被自动保存
- 下次打开网页自动恢复

## 常见问题

### Q1：背景图片不显示？
**可能原因：**
- 图片上传失败：重新上传
- 背景被禁用：点击 👁️ 开启
- 图片过大：自动压缩失败，换个小图

### Q2：文字颜色不自动变化？
**解决方法：**
1. 确认背景已开启
3. 重新上传图片触发分析

### Q3：某些区域背景不透明？
**解决方法：**
1. 开启 🔮 极致透明模式
2. 手动点击“🧹 手动透明”
3. 某些网站可能有特殊结构，暂时无法处理

### Q4：环绕小球不见了？
**恢复方法：**
- 刷新页面
- 检查是否被其他元素遮挡
- 脚本可能被禁用

### Q5：如何恢复默认设置？
**方法一（清除当前网站）：**
1. 打开开发者工具（F12）
2. 在控制台输入：
   ```javascript
   GM_setValue('bgSettingsV2', null);
   location.reload();
   ```

**方法二（完全重置）：**
在油猴管理面板中删除脚本并重新安装

### Q6：性能问题？
- 背景图片已压缩，通常不影响性能
- 如遇卡顿，降低图片分辨率或增加模糊值
