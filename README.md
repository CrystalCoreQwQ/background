## 简介

通用背景板是一个强大的网页背景自定义工具，它可以让你为任意网站设置自定义背景图片，并智能调整文字颜色，让阅读体验更舒适。每个网站都可以独立保存设置，真正做到“一网站一背景”。

**核心特点：**
- 🖼️ 上传任意图片，裁剪为当前窗口比例
- ☀️ 亮度调节（0-200%）
- 🌫️ 模糊调节（0-20px）
- 🎨 智能文字颜色（自动/白色/黑色）
- 🔮 极致透明模式（强制清除所有背景）
- 💻 代码框永久透明（对编程网站特别友好）
- 📍 悬浮球可拖动，双击展开/收缩

## 快速开始

### 安装脚本
1. 确保你已经安装了 Tampermonkey 或 Violentmonkey 浏览器扩展
2. 点击安装脚本（或创建新脚本并粘贴代码）
3. 刷新任意网页，你会看到右下角出现一个蓝色小球 🎨

### 第一个背景
1. **双击蓝色小球**展开环绕菜单
2. 点击 **📁**（上传背景）
3. 选择一张你喜欢的图片
4. 在裁剪框中调整位置（比例已锁定为当前窗口）
5. 点击“确认裁剪” → 背景立即生效！

## 界面说明

### 主控制球（蓝色）
- **位置**：默认右下角，可随意拖动
- **单击**：暂未绑定功能（预留）
- **双击**：展开/收缩环绕小球菜单
- **拖动**：按住蓝色球可移动位置（需先收缩菜单）

### 环绕小球（展开后显示）
| 图标 | 功能 | 说明 |
|------|------|------|
| 📁 | 上传背景 | 打开文件选择器，上传新图片 |
| ☀️+ | 亮度 +10% | 增加背景亮度 |
| ☀️- | 亮度 -10% | 降低背景亮度 |
| 🌀+ | 模糊 +1 | 增加模糊程度 |
| 🌀- | 模糊 -1 | 降低模糊程度 |
| 🎨 | 文字颜色 | 循环切换：自动→白色→黑色 |
| 🔮 | 极致透明 | 开关：强制清除所有背景元素 |
| ⚙️ | 更多 | 打开高级功能面板 |

| 按钮 | 功能 | 说明 |
|------|------|------|
| ⭐ 设为全局默认 | 将当前设置应用到所有没有独立设置的网站 |

| 🧹 手动透明 | 手动触发一次代码框透明清理 |
| 🔍 调试遮罩 | 给背景层添加半透明红色，帮助定位问题 |

## 详细功能

### 1. 图片上传与裁剪
- 支持格式：jpg、png、gif 等常见图片格式
- 裁剪比例：自动锁定为当前浏览器窗口的宽高比
- 压缩机制：自动将大图片压缩至 2.5MB 以内，避免存储溢出
- 裁剪框可自由移动和调整大小（但保持比例）

### 2. 亮度调节
- 范围：0% (全黑) 到 200% (过曝)
- 调节方式：点击☀️+/- 每次增减10%
- 适用场景：图片太亮导致文字看不清时调暗，或太暗时调亮

### 3. 模糊调节
- 范围：0px (清晰) 到 20px (高度模糊)
- 调节方式：点击🌀+/- 每次增减1px
- 适用场景：让背景不那么抢眼，突出前景文字

### 4. 智能文字颜色
三种模式循环切换：

| 模式 | 效果 | 适用场景 |
|------|------|----------|
| **自动** | 分析图片中央区域亮度，深色背景配白字，浅色背景配黑字 | 大多数情况 |
| **白色** | 强制文字为白色 | 深色背景图片 |
| **黑色** | 强制文字为黑色 | 浅色背景图片 |

> 💡 链接颜色也会相应调整（深色背景时变亮，浅色背景时保持蓝色）

### 5. 极致透明模式
- 开启后，脚本会强制清除页面上几乎所有元素的背景色
- 包括：卡片、面板、侧边栏、评论区等常见容器
- **注意**：部分网站可能会因此失去视觉层次，可随时关闭

### 6. 代码框永久透明
- 自动覆盖常见代码高亮库的样式
- 支持：Highlight.js、Prism.js、CodeMirror、Monaco Editor、Shiki 等
- 动态监听：新加载的代码块也会自动透明化

### 7. 多网站独立设置
- 每个域名自动保存独立的背景配置
- 访问新网站时自动加载该网站的设置（如果有）
- 如果没有独立设置，则使用“全局默认”配置

## 使用场景示例

### 场景1：编程文档网站（如 MDN、Stack Overflow）
```
1. 上传一张柔和的深色图片
2. 亮度调至80%，模糊3px
3. 开启极致透明模式
4. 文字颜色设为白色或自动
→ 获得沉浸式阅读体验，代码框保持透明
```

### 场景2：新闻阅读网站（如 BBC、知乎）
```
1. 上传一张浅色纹理图片
2. 亮度保持100%或稍高
3. 文字颜色设为黑色
4. 关闭极致透明（保留卡片边界）
→ 背景不刺眼，阅读舒适
```

### 场景3：视频网站（如 B站、YouTube）
```
1. 上传与观看内容相关的图片
2. 模糊5-10px，亮度80%
3. 极致透明开启
→ 背景不干扰视频观看，评论区透明
```

### 场景4：工作学习时统一风格
```
1. 找到一张喜欢的背景图
2. 点击⚙️ → “应用到所有”
3. 所有网站都使用同一张背景
4. 再微调个别网站的特殊需求
```

## 常见问题

### Q1：背景图片保存到哪里了？
A：图片以 DataURL 形式保存在 Tampermonkey 的存储中（GM_setValue）。每个网站独立存储，不会上传到任何服务器。

### Q2：存储空间不够怎么办？
A：脚本会自动压缩图片至 2.5MB 以内。如果仍然不够，建议使用较小尺寸的图片（如 1920x1080 左右）。

### Q3：为什么有些网站背景不生效？
A：可能原因：
- 网站使用了极高的 z-index 层级（但我们的背景层在 z-index: -2147483648，理论上最低）
- 网站有 `background-attachment: fixed` 等特殊样式
- 尝试开启“极致透明模式”或“手动透明”按钮

### Q4：如何重置某个网站的设置？
A：目前没有一键重置按钮，但你可以：
1. 上传一张纯色小图片作为“清除”
2. 或者手动修改存储（GM_setValue），删除对应域名的配置

### Q5：拖动悬浮球时菜单展开了怎么办？
A：收缩状态才能拖动。如果菜单展开了，先双击收缩，再拖动。

### Q6：文字颜色自动判断不准确？
A：自动模式只采样图片中央25-75%区域。如果图片边缘与中央差异大，可以：
- 手动切换到白色/黑色模式
- 或者在裁剪时把主要内容区域放在中央

### Q7：脚本会影响网页性能吗？
A：影响极小。背景层使用固定定位，没有动画循环。只有上传图片时会短暂解码图片。

### Q8：如何备份我的所有背景设置？
A：目前没有导出功能。你可以：
- 在 Tampermonkey 管理面板中找到“存储”选项卡
- 复制 `bgSettingsV2` 的值保存为文本文件

## 高级技巧

### 技巧1：使用透明背景
上传一张完全透明的 PNG，可以实现“无背景但有亮度/模糊调节”的效果。

### 技巧2：快速切换配色
连续点击 🎨 小球可以在三种文字颜色模式间快速切换，找到最适合当前页面的配色。

### 技巧3：调试模式
点击“调试遮罩”会给背景层加上半透明红色，帮助你确认背景层是否正常工作。

### 技巧4：多设备同步
如果你在多台设备使用 Tampermonkey 同步功能，背景设置也会同步（取决于浏览器的同步机制）。
